# 验证方法和限制

## 可以复现的检查

```bash
python3 -m unittest discover -s tests -v
python3 workbench.py audit
python3 workbench.py validate-draft --draft examples/ai-draft.example.json
python3 scripts/check_public.py
```

回归用例覆盖：金额汇总、Decimal精度、丢单及取消排除、来源冲突、待确认记录隔离、签约合同门槛、缺失预算/决策角色、采购日过期、更新提醒、未知ID、来源归属、无效金额和日期、六模块输出、知识过期、HTML转义、AI草稿字段校验、输入不变性、重复运行一致性与CLI失败时不写输出。

测试文件是代码的直接证据，测试数量和通过状态以实际运行输出为准。子测试中的多个输入不单独算一条测试方法。

## 预期样例结果

8条记录中，2条暂缓汇总（金额冲突与未确认转述各1条）；1条已确认签约32000元；3条已确认在途合计316000元；2条丢单/取消不计入在途。该结果没有使用真实业务数据。

## 人工复核用例

| 用例 | 期望行为 | 检查方式 |
|---|---|---|
| 两份来源金额不同 | 不自动采用更新来源 | 查看SYN-O03、conflicts及held标记 |
| 转述未确认 | 不进入已确认成果 | 查看SYN-O07 |
| 只有测试意向 | 不升级到签约 | 检查validation阶段及签约合计 |
| 来源包含HTML | 文本显示而非执行 | HTML转义回归用例 |
| AI篡改金额或阶段 | 结构校验失败 | 修改示例草稿后运行validate-draft |
| AI新增无来源语义 | 交人工阅读 | 自动校验无法完整判断 |
| 知识条目已过期 | 标为历史，不承诺当前有效 | 查询“服务”，检查SYN-K02 |

## 尚未验证

- 未自动调用在线模型，没有模型准确率、幻觉率或提示注入成功率结论。
- 没有真实客户试验、生产部署、多用户权限或CRM写回验证。
- 没有测量人工工作节省时长、业务收入提升或真实销售转化提升。
- 示例签约金额不是作者实际业绩，不可写入简历充当业务成果。
- 检查器是演示级规则，不是财务核算、法务、DLP或全面事实核验系统。
- Windows的命令写法已提供，但跨操作系统实机结果以各自实际测试为准。
